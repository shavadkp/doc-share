# AI Workflow Note

## AI Tools Used

* ChatGPT

## How AI Helped

AI was used to accelerate development by assisting with:

* Django REST API scaffolding
* React component scaffolding
* Route generation
* Editor integration planning
* General debugging support

## What Was Modified

AI-generated code was reviewed and modified before use.

Examples:

* API endpoint adjustments
* Authentication fixes
* React component updates
* File upload integration

## What Was Rejected

Some generated code was simplified or rewritten when:

* It added unnecessary complexity
* It did not match project requirements
* It reduced readability

## Verification Process

Correctness and reliability were verified through:

### Backend

* Manual API testing with Postman
* Authentication testing
* File upload testing
* Sharing workflow testing

### Frontend

* End-to-end browser testing
* Document editing validation
* Save/reload validation
* Upload validation

### Automated Testing

Implemented automated tests for:

* Document creation
* Document sharing

AI accelerated implementation, but all functionality was manually verified before submission.
